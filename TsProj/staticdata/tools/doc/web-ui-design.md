# staticdata 本地工作台

## 定位

- 工作台服务高密度静态表浏览和编辑，优先保证响应速度、信息可读性和写入安全。
- Web、CLI 与 MCP 共用 `StaticDataService`、schema、validation、preview/apply 和 diff，不建立页面专用数据协议。
- 所有写入绑定 workspace revision；revision 变化、token 过期或重复 apply 必须拒绝。

## 页面结构

- 默认进入逻辑表目录；首屏只加载目录所需信息，不预取全量记录、lookup 或详情。
- 表格视图负责筛选、排序、分页和多行草稿；单元格进入编辑时才创建对应控件。
- 固定主键列只展示一次；记录接口保留其原始 authored 值，网格保存草稿时将该值写回完整记录快照，不依赖字符串化的行 ID。
- 新增记录时将输入的记录 ID 回填到 authored 固定主键；字段可用 `metadata.createDefault: "recordId"` 声明同值初始化，数值字段要求记录 ID 可转换为有限数值。
- 详情视图负责单条记录的 core、sidecar 和结构化字段编辑。
- 变更摘要展示将要写入的内容、影响范围和校验问题；内部 canonical plan 保留在调试信息中。
- 浏览器导航和 URL 恢复当前表、分类、筛选、排序、分页与搜索上下文。

## 顺序与大表

- 默认保持 authoring 记录与字段顺序；显式排序只改变当前视图，普通编辑不重排数据。
- 主键与操作入口在横向滚动时保持可定位；动态 map 和高稀疏结构使用可逆 JSON 编辑，不强行展开成无限列。
- 服务端在构建单元格前应用筛选、排序和分页；宽表按字段扇出收紧实际页容量。
- 同一表格视图使用固定页容量，页码按固定容量计算 offset；大型结构化字段不改变当前视图的页容量。
- lookup、详情、引用和嵌套数据按需加载，并复用同一 revision 下的结果。

## 搜索与引用

- 表内搜索覆盖当前表的 authored 与 resolved 值，并与逐列筛选组合。
- 目录搜索、表内搜索和逐列筛选在停止输入 700ms 后提交；输入法组合期间只更新输入草稿，不提交查询或重绘网格，组合结束后再重新计时。
- 输入法候选选择使用的 Enter 不提交查询；显式搜索结果更新后保留搜索输入的值、焦点、光标和选区。
- 全局搜索按记录聚合跨表命中，使用 revision-bound cursor；完整属性、validation 和引用关系在打开检查器时加载。
- incoming/outgoing ref 跳转保持搜索上下文和面包屑；定位回表格时打开需要的分类/sidecar 并突出目标字段。
- 乱序响应不能覆盖更新的输入或关闭当前有效 loading。

## 交互反馈

- 进入视图、分页、排序和刷新显示导航状态；后台筛选和搜索保留当前内容与输入焦点。
- 表格分页提供首页、上一页、页码输入、下一页和末页；目标页超出范围时收敛到有效页。
- 网格字段列使用稳定的表头高度和筛选行吸附偏移；标题单行省略，悬停可查看完整字段名称、说明和类型信息；仅存在字段条件提示时增加表头高度。
- 网格字段参与条件必填、条件禁填或互斥组时，表头以紧凑只读提示展示当前字段的依赖角色；控制字段、目标字段和条件互补的必填/禁填规则合并为单条“控制/受控”提示，悬停可查看完整条件和关联字段；该提示不改变字段编辑能力。
- 对象字段可通过 `metadata.gridColumns: "children"` 将直接子字段显示为独立网格列；网格编辑按结构化字段路径回写，authoring 数据与 runtime target 仍保持对象结构。
- loading 区分请求、渲染和首次绘制阶段，并只由当前有效请求结束。
- 未保存草稿只在实际离开或提交新查询时确认，不在每次键入时打断。
- `string` 字段可通过 `metadata.multiline: true` 固定使用多行编辑器；未声明时，authored 或 resolved 值包含真实 CR/LF 也自动使用 textarea。`path` 和 `ref` 保持单行控件。
- 以独立字段或网格列呈现的 `unity-image` path 显示固定尺寸缩略图；图片按可见性懒加载，路径编辑后刷新预览，空值、非法路径和加载失败使用稳定占位状态，加载状态切换不改变表格行列尺寸。
- 网格未编辑状态将字符串中的真实 CRLF、CR、LF 统一显示为可见的 `\n`，不改写底层值；进入编辑后 textarea 保留真实换行。字面量反斜杠加 `n` 保持原样。
- 网格的单行编辑控件支持 TSV 多单元格粘贴；结构化字段和多行字符串使用 textarea，包含换行的内容通过浏览器原生粘贴只写入当前单元格。
- 工作台在 document capture 阶段接管 `Ctrl+S` / `Cmd+S`；网格和详情页保存各自当前草稿，无可保存内容时给出状态反馈。表格工作台右上角提供“保存当前表”命令，按钮复用快捷保存入口，并在存在可解析草稿时立即启用。保存入口取消尚未触发的 debounce 并立即为当前 payload 生成 preview；相同 navigation generation 与 payload 的进行中 preview 由自动检查和保存复用。preview 与 apply 只向页面返回本次变更及派生影响记录所需的 resolved 数据。apply 前 payload 已变化时不提交旧 preview，apply 进行中产生的编辑则在已提交 payload 成为新 baseline 后继续保留为草稿。保存进行中再次触发保存时合并为一次最新内容保存；保存回包绑定发起时的页面 identity，不覆盖之后导航到的页面。校验、revision 或请求失败时保留草稿并显示对话框。
- backend 声明字段迁移能力时，普通 core 列表头提供导出字段改名和删除入口；执行前显示影响范围，应用后刷新 schema。

## 验收

- 首屏不传输完整 workspace 数据；进入表、详情和 ref 编辑器只加载当前动作需要的数据。
- 工作台从无浏览器构建产物的工作区启动时会先完成前端构建；浏览、编辑和图片预览直接消费 authoring 与 schema，不要求预先生成 runtime target。
- 宽表进入、翻页和编辑保持可操作，不因一次性创建全页控件阻塞主线程；性能基线由 benchmark 和浏览器实测持有。
- 默认浏览、编辑、保存和刷新保持 authoring 顺序；显式排序可恢复自然顺序。
- 搜索、引用跳转、详情和 apply 在 workspace revision 变化时明确失效，不静默读取或写入新状态。
- 表格与详情继续使用公共 validation、diff 和事务写回链。
- 多行字符串经过编辑、preview、apply、工作区重载和网格接口往返后保留真实换行。
- 浏览器不响应工作台内的网页保存快捷键；快捷保存不会绕过 preview、revision 和 apply 校验。
